# STYLE LOCK (documentary) — paste into every documentary prompt, unchanged

For the 16:9 animated-documentary look (true story, crime, missions, history). The flat cel lock in `style-lock.md` stays for
the close-up fight Shorts; do not mix the two in one video.
Attach: the first approved keyframe of the video (or `assets/refs/doc_style.png`, once one exists) as the style reference,
plus the person's cast sheet from `assets/refs/`.

```
STYLE: cinematic 2D graphic-novel illustration for an animated documentary. Semi-realistic Indian faces and proportions,
thin clean dark linework, soft cel shading with painted lighting (warm lamp light, window light shafts, neon or moonlight at night),
detailed lived-in period backgrounds, muted film colours: amber and brown interiors, teal and blue nights, desaturated daylight.
Subtle film grain. Looks like a frame from a high-end animated crime documentary, NOT anime, NOT flat vector, NOT 3D, NOT a photo.
No text, no captions, no logos, no watermarks anywhere in the picture.
Violence is only implied (no blood, no wounds, no gore, no bodies).
```

## Add to KEYFRAME images (one shot)

```
FRAME: LANDSCAPE 1536x1024, one single shot filling the whole canvas, no borders. Camera: [wide / medium / close-up / over-the-shoulder /
low angle / top view]. Leave a little empty space around the main figure so a slow camera push-in does not crop the head.
```

## Add to GRID images (4 shots in one generation)

```
LAYOUT: LANDSCAPE 1536x1024 canvas split into a 2x2 grid of 4 equal landscape panels separated by thin pure white gutters.
Each panel is a separate film shot of the same scene, consistent characters, lighting and colours across all four.
```

## Add to CAST sheets

```
CAST SHEET: LANDSCAPE 1536x1024, plain flat light-grey background (#BDB8AE). The same person 4 times at the same scale on one baseline:
front, three-quarter, side profile, and a head-and-shoulders close-up. Full body for the first three, nothing cropped. No text.
```

## Add to LOCATION plates

```
LOCATION PLATE: LANDSCAPE 1536x1024, the empty place with absolutely no people, eye-level camera, horizon around 55% from the top,
clear floor in the middle so characters can be placed there later.
```
